## What changes

**One image, isolated with Docker by default.** A computer runs answers,
workshop processes and builds in one image, `stemma/stemma-<version>`,
which it builds with `stemma machine image`. How it isolates them is set in
a new `[machine]` table: `isolation` (`docker` by default, `podman`, or
`none`, which the doctor advises against), `image`, `cpus` and `memory`.

**Recipes are a script and its files.** A recipe is now a folder of the
group's `recipes` repository: `recipe.toml`, `run.sh` and `files/`.
Starting a task runs `run.sh`, with the request's inputs in place. It
launches the request's agent with `stemma agent run`, and delivers
messages and pull requests with `stemma output`. A recipe says which
outputs a run may deliver, and what else it may do in the group.

**People approve merges.** Every pull request a process opens gets a card
in its request. The hub prepares its merge into `main`, and when it
conflicts, the group's model resolves it and explains how. The requester
or an admin approves, and the hub makes a true merge commit. The model no
longer reviews or merges on its own.

**Only an admin steps down.** An admin can no longer demote or remove
another admin.

## Upgrading

These changes break earlier settings and recipes.

- **On each computer**, remove `isolation`, `image`, `cpus` and `memory` from
  `[agents]`, and `image`, `cpus` and `memory` from `[workshop]`; set them in
  `[machine]` only to change the defaults. Settings with the old keys no
  longer load. Then build the new image with `stemma machine image`. Images of earlier versions,
  `stemma-agents` and `stemma-workshop`, can be removed.
- **On the hub**, the image now includes git, which merges need, 2.38 or
  later. Starting the new version cancels workshop requests still open from
  earlier recipes. Approving a merge needs Forgejo 7 or later.
- **In each group's `recipes` repository**, replace `general.md` with the
  folder `general/` from `recipes/template/` in Stemma's repository, and
  turn other recipes into folders, as [Writing
  recipes](https://stemma-math.github.io/stemma-exedra/guide/recipes) says.
  The hub no longer reads Markdown files at the root.
