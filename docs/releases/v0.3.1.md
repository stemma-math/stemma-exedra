## What changes

**Every group has a general recipe.** The hub provides `general` to every
group, so a request in plain words always has a recipe that fits. A
group's own `general/` folder in its `recipes` repository replaces it.

**A forgotten password can be reset.** On the hub's machine, `stemma hub
reset-password --username <name>` sets a new password and signs the
person out everywhere. Their tokens keep working.

**The machine's service finds the system's certificates.** When the
computer sets where its certificates are, with `SSL_CERT_FILE`,
`NIX_SSL_CERT_FILE` and the like, the service keeps those settings, so
agents run without isolation can reach their providers.

## Upgrading

- **On each computer**, run `stemma machine stop` and `stemma machine
  start` from a terminal, so the service picks up where the certificates
  are, and build the new image with `stemma machine image`.
- **In each group's `recipes` repository**, a `general/` folder copied
  from `recipes/template/` may be removed, unless the group changed it.
