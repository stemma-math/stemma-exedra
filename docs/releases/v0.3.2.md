## What changes

**Libraries of groups with a hyphen in their name build.** A new group's
library names its package in `lake-manifest.json` as Lake reads it, within
«» when the name is not an identifier, as `number-theory` is not. Lake
refused the manifest before, so these libraries never built.

**The workshop says less.** A request that names its recipe launches
without waking the orchestrator, which no longer posts that it is queued.
When a process has reported in the thread, the orchestrator closes the
request in one sentence instead of repeating the report.

**Attachments download in the app.** The desktop app saves an attachment
to the Downloads folder and shows it there.

## Upgrading

- **In each group whose name has a hyphen**, an admin changes `"name"` in
  the library's `lake-manifest.json` to the name within «», for example
  `"name": "«number-theory»"`, and pushes it to `main`.
- **On each computer**, build the new image with `stemma machine image`.
